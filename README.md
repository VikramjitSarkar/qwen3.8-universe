# UNIVERSE · An Interactive Cosmos

An interactive universe website — scale, orbits, a timeline and a gravity playground — **written entirely by Qwen 3.8 27B running locally** on a MacBook Pro M5 (32GB). No cloud, no API keys.

**Live demo:** https://vikramjitsarkar.github.io/qwen3.8-universe/

It's a single self-contained `index.html` — open it in any modern browser.

Built for the video *Qwen 3.8 27B local LLM test on MacBook Pro M5 32GB* on the [IamVikramjit](https://www.youtube.com/@IamVikramjit) channel.
